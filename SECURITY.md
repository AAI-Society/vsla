# Security policy

This repository holds a specification, a JSON schema and a reference verifier.

To report a vulnerability in the specification or in the reference verifier, use GitHub private vulnerability reporting
(the Security tab of this repository), or contact the maintainers through the Advanced AI Society.
Do not open a public issue for a flaw that lets an attack succeed against a deployed system.

A report that the verifier grants a level it did not check is welcome as a public issue once no deployed system is
affected.
Say which requirement or check is bypassed and include a failing test where you can.
