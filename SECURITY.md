# Security policy

This repository holds a specification, a JSON schema and a reference verifier.

To report a vulnerability that affects a deployed system (an intake or verifier built on VSLA), contact the maintainers
privately through the Advanced AI Society (https://advancedaisociety.org) and do not open a public issue.

A report that the reference verifier grants a level it did not check is welcome as a public issue or pull request once
no deployed system is affected.
Say which requirement or check is bypassed and include a failing test where you can.
