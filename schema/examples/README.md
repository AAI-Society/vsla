# Examples

Generated by `tools/make_examples.py` with fresh keys; every signature is real.

| File | What |
|---|---|
| `finding-l1.dsse.json` | Finding track, claimed L1, finder signature only |
| `finding-l2.dsse.json` + `.receipt.dsse.json` | claimed L2 in the **embargoed profile** (command and test path are digests); declared channel and history; the platform's receipt is a separate DSSE envelope with a `log-inclusion` anchor (signed checkpoint + inclusion proof under a pinned log key) |
| `finding-l3.dsse.json` + `.receipt.dsse.json` | claimed L3: every model served from the attested environment with a provider-signed weight attestation; `signed-quote` environment whose quote binds enclave key, harness, weights and sandbox; enclave signature |
| `patch-l1.dsse.json` | Patch track, claimed L1: the finder's own three executions |
| `patch-l2.dsse.json` + `.receipt.dsse.json` | claimed L2: the receipt carries the platform's re-execution, its own review on a distinct model family, and the computed scope; the ledger is the finder's Patch-track ledger |
| `patch-l3.dsse.json` + `.receipt.dsse.json` | claimed L3 |
| `keyring.json` | pinned keys by `role:name` (finder, platform, maintainer, provider, root, log) |
| `expectations.json` | the receiver's reference values: harness digests per version, allowlisted measurements |
| `report.json` | the report the subject digest is computed from |
| `leaves.json` | the transcript leaves behind the Merkle root (leaf 0 measures, leaf 6 verifies) |
| `ledger.json`, `ledger-patch.json` | the finder's ledgers, one per track: DSSE entries countersigned by three pinned keys, each naming the finder's key and the track; no entry carries an index (the finder's operator owns the order) |
| `reexecution.json`, `reexecution-patch.json` | a verifier's own re-execution result, per track |

```bash
python tools/vsla_verify.py schema/examples/finding-l3.dsse.json --keyring schema/examples/keyring.json \
    --expectations schema/examples/expectations.json --report schema/examples/report.json --leaves schema/examples/leaves.json \
    --ledger schema/examples/ledger.json --receipt schema/examples/finding-l3.receipt.dsse.json \
    --reexec schema/examples/reexecution.json --intake https://cvd.example.org/mcp --require-anchor
```

Drop `--ledger` and Identity stops at L1 (a self-reported summary is not evidence). Drop `--expectations` and
Environment stops at L1 (nothing to compare the measured harness to). Drop `--reexec` and `--receipt` and Evidence
stops at L1 (nobody but the finder ran the test). Pass `ledger.json` to a `patch-*` statement and Identity stops at
L1 (a Finding record buys no Patch trust). Sign a receipt with any key but the pinned platform key and I3 fails.
Pass `--required-entries` with an entry the ledger omits and I4 says `ledger-fork`; reorder the ledger and the root
no longer matches `history.root`, while the score (a window by countersigned time) does not move.
